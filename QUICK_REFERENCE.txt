🔐 AUTHENTICATION FLOW
================================================================================
1. User logs in → POST /auth/login
2. Receives JWT access token + refresh token
3. Access token stored in localStorage
4. All API requests include: Authorization: Bearer <token>
5. Token includes: userId, tenantId, role
6. Middleware extracts tenantId for multi-tenancy

🏢 MULTI-TENANCY
================================================================================
- Each hospital = 1 tenant
- tenantId in JWT token
- Automatic tenant filtering in Prisma queries
- Tenant middleware on all routes
- Data isolation per tenant

👥 ROLE-BASED ACCESS CONTROL
================================================================================
Roles:
- SUPER_ADMIN      # Platform admin
- HOSPITAL_ADMIN   # Hospital owner
- DOCTOR           # Medical staff
- NURSE            # Nursing staff
- RECEPTIONIST     # Front desk
- PHARMACIST       # Pharmacy staff
- LAB_TECHNICIAN   # Lab staff
- ACCOUNTANT       # Finance staff

Guards:
- JwtAuthGuard     # Requires authentication
- RolesGuard       # Requires specific role
- TenantGuard      # Tenant isolation

Usage:
@UseGuards(JwtAuthGuard, RolesGuard)
@Roles(UserRole.HOSPITAL_ADMIN, UserRole.DOCTOR)

📡 API PATTERNS
================================================================================
All endpoints follow REST conventions:

GET    /resource           # List (paginated)
POST   /resource           # Create
GET    /resource/:id       # Get one
PUT    /resource/:id       # Update
DELETE /resource/:id       # Delete

Query params:
?page=1&limit=10           # Pagination
?search=term               # Search
?status=active             # Filtering

Response format:
{
  items: [...],            # For list endpoints
  total: 100,
  page: 1,
  pages: 10
}

🔧 TROUBLESHOOTING
================================================================================
Issue: Vercel build fails
Fix: Check build logs, ensure all dependencies installed

Issue: Database connection fails
Fix: Verify DATABASE_URL in Vercel environment variables

Issue: API returns 500
Fix: Check Vercel function logs for error details

Issue: Frontend can't reach API
Fix: Verify NEXT_PUBLIC_API_URL is correct

Issue: Prisma client out of sync
Fix: Run `npx prisma generate`
