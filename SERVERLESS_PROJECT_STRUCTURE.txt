API ENDPOINTS (Sample)
================================================================================

AUTHENTICATION:
POST   /auth/login                  # User login
POST   /auth/signup                 # User registration
POST   /auth/refresh                # Refresh token
POST   /auth/logout                 # User logout

PATIENTS:
GET    /patients                    # List patients (paginated)
POST   /patients                    # Create patient
GET    /patients/:id                # Get patient details
PUT    /patients/:id                # Update patient
DELETE /patients/:id                # Delete patient

APPOINTMENTS:
GET    /appointments                # List appointments
POST   /appointments                # Create appointment
GET    /appointments/:id            # Get appointment
PUT    /appointments/:id            # Update appointment
DELETE /appointments/:id            # Cancel appointment

OPD:
GET    /opd                         # List OPD visits
POST   /opd                         # Create OPD visit
GET    /opd/:id                     # Get OPD visit
PUT    /opd/:id                     # Update OPD visit

BILLING:
GET    /billing/invoices            # List invoices
POST   /billing/invoices            # Create invoice
GET    /stripe-billing/plans        # Get subscription plans
POST   /stripe-billing/subscribe    # Subscribe to plan

ANALYTICS:
GET    /analytics/kpis              # Get KPIs
GET    /analytics/trend/monthly     # Monthly trends

ADMIN:
GET    /admin-rbac/roles            # List roles
POST   /admin-rbac/attach-permission # Attach permission to role

DEPLOYMENT WORKFLOW
================================================================================

1. CODE PUSH:
   git add .
   git commit -m "message"
   git push origin main

2. VERCEL AUTO-DEPLOY:
   - Detects push to main branch
   - Runs build for both frontend and backend
   - Deploys to production URLs

3. DATABASE MIGRATIONS:
   - Run manually: npx prisma migrate deploy
   - Or auto-run via build script

4. MONITORING:
   - Vercel Dashboard for logs
   - Supabase Dashboard for database
   - Stripe Dashboard for payments
