================================================================================
AFTER LINKING: HOW AUTO-DEPLOY WORKS
================================================================================

Once linked, this is the flow:

1. You make changes in apps/api/
2. You commit: git commit -m "fix: something"
3. You push: git push origin main
4. GitHub webhook triggers Vercel
5. Vercel detects changes in apps/api/
6. Vercel starts build automatically
7. Runs: npm run build:vercel
8. Generates Prisma client
9. Builds NestJS app
10. Deploys to production
11. Health check passes
12. ✅ Live at: https://hma-saas-api.vercel.app

All automatic! No manual intervention needed! 🎉

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "vercel link" command not found
Fix: npm install -g vercel

Issue: "vercel login" doesn't open browser
Fix: Copy the URL shown and paste in browser manually

Issue: Can't find project "hma-saas-api"
Fix: 
- Make sure you're logged into correct Vercel account
- Check project name is exactly: hma-saas-api (with hyphen)
- Try: vercel projects ls (to list all projects)

Issue: Link succeeds but still no auto-deploy
Fix:
- Check Vercel Dashboard → Settings → Git
- Verify "Root Directory" is set to: apps/api
- Verify "Automatic Deployments" is enabled
- Try manual redeploy once to initialize

Issue: Build fails after auto-deploy
Fix:
- Check environment variables are set
- Check build command is: npm run build:vercel
- Check output directory is: dist
