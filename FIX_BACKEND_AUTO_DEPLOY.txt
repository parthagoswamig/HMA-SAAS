WHY THIS HAPPENS
================================================================================

Vercel has 2 ways to configure builds:

Method 1: Dashboard Settings (Modern, Recommended)
- Set in Vercel Dashboard UI
- Auto-deploy works automatically
- Easy to change

Method 2: vercel.json "builds" (Deprecated)
- Old method from Vercel v1/v2
- Overrides dashboard settings
- Disables auto-deploy features
- Shows warning in logs

Your vercel.json uses Method 2 (deprecated)
This is why auto-deploy doesn't work!
