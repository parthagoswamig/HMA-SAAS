PART 3: DEPLOYMENT ORDER & UPDATES
================================================================================

STEP 1: Deploy Backend First
-----------------------------
1. Go to apps/api directory
2. Run: vercel --prod
3. Note the deployment URL (e.g., https://hma-saas-api.vercel.app)
4. Add all backend environment variables in Vercel dashboard
5. Redeploy if needed: vercel --prod

STEP 2: Update Backend CORS
----------------------------
After you know your frontend URL:
1. Go to backend project settings in Vercel
2. Update CORS_ORIGINS to: https://hma-saas-web.vercel.app
3. Update FRONTEND_URL to: https://hma-saas-web.vercel.app
4. Redeploy backend: vercel --prod

STEP 3: Deploy Frontend
-----------------------
1. Go to apps/web directory
2. Update NEXT_PUBLIC_API_URL with your backend URL from Step 1
3. Add all frontend environment variables in Vercel dashboard
4. Run: vercel --prod
5. Note the deployment URL (e.g., https://hma-saas-web.vercel.app)

STEP 4: Verify Everything
--------------------------
1. Test backend: curl https://hma-saas-api.vercel.app/health
2. Test frontend: Open https://hma-saas-web.vercel.app
3. Test auth flow: Register → Login → Dashboard
4. Check browser console for errors
5. Check Vercel logs for any issues

PART 5: IMPORTANT NOTES
================================================================================

⚠️ SECURITY WARNINGS:
---------------------
1. Never commit .env files to git
2. Use Vercel dashboard to set environment variables (encrypted)
3. Rotate JWT secrets periodically (quarterly recommended)
4. Use LIVE payment keys only in production
5. Keep SUPABASE_SERVICE_ROLE_KEY secret (backend only)

🔄 DATABASE URLS:
-----------------
• DATABASE_URL (port 6543): For serverless functions (pooled)
• DIRECT_DATABASE_URL (port 5432): For migrations only (direct)
• Always use pgbouncer=true for serverless
• Always use connection_limit=1 for serverless

🌐 CORS CONFIGURATION:
----------------------
• CORS_ORIGINS must match your frontend URL exactly
• Include protocol (https://)
• No trailing slash
• Update after deploying frontend

📝 PAYMENT KEYS:
----------------
• Current keys are TEST keys (rzp_test_xxx)
• Replace with LIVE keys for production (rzp_live_xxx)
• Get live keys from Razorpay dashboard
• Test in staging environment first

PART 7: TROUBLESHOOTING
================================================================================

Issue: CORS errors
Solution: Verify CORS_ORIGINS matches frontend URL exactly

Issue: Database connection errors
Solution: Verify DATABASE_URL uses port 6543 with pgbouncer=true

Issue: JWT errors
Solution: Verify all JWT secrets are set and match

Issue: Frontend can't reach API
Solution: Verify NEXT_PUBLIC_API_URL is correct

Issue: Build fails
Solution: Check Vercel build logs, verify all required env vars are set
