================================================================================
WHY SEPARATE PROJECTS?
================================================================================

Monorepo with 2 apps needs 2 Vercel projects because:

1. Different build commands
   - Frontend: npm run build (Next.js)
   - Backend: npm run build:vercel (NestJS)

2. Different root directories
   - Frontend: apps/web
   - Backend: apps/api

3. Different environment variables
   - Frontend: NEXT_PUBLIC_*
   - Backend: DATABASE_URL, JWT_SECRET, etc.

4. Independent deployments
   - Frontend changes don't redeploy backend
   - Backend changes don't redeploy frontend
