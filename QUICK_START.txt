HMS SAAS - SERVERLESS DEPLOYMENT QUICK START
================================================================================

🚀 FASTEST PATH TO DEPLOYMENT
================================================================================

STEP 1: INSTALL VERCEL CLI
---------------------------
npm install -g vercel

STEP 2: RUN MIGRATIONS
----------------------
cd apps/api
$env:DIRECT_DATABASE_URL="postgresql://postgres.[PROJECT]:[PASS]@aws-0-[REGION].pooler.supabase.com:5432/postgres"
npm run prisma:migrate:deploy

STEP 3: DEPLOY BACKEND
----------------------
cd apps/api
vercel

# In Vercel dashboard, add these environment variables:
# - DATABASE_URL (with port 6543, pgbouncer=true)
# - DIRECT_DATABASE_URL (with port 5432)
# - JWT_SECRET, JWT_ACCESS_SECRET, JWT_REFRESH_SECRET
# - CORS_ORIGINS, FRONTEND_URL
# - SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY
# - VERCEL=1

vercel --prod

STEP 4: DEPLOY FRONTEND
-----------------------
cd apps/web
vercel

# In Vercel dashboard, add these environment variables:
# - NEXT_PUBLIC_API_URL (your backend URL from step 3)
# - NEXT_PUBLIC_SUPABASE_URL
# - NEXT_PUBLIC_SUPABASE_ANON_KEY
# - NEXT_PUBLIC_APP_ENV=production

vercel --prod

STEP 5: VERIFY
--------------
curl https://your-api.vercel.app/health
Open https://your-frontend.vercel.app

✅ DONE!

================================================================================
🐛 TROUBLESHOOTING
================================================================================

Database Connection Error:
→ Use port 6543 with pgbouncer=true for DATABASE_URL
→ Use port 5432 for DIRECT_DATABASE_URL (migrations only)

CORS Error:
→ Add frontend URL to CORS_ORIGINS in backend env vars

Cold Start Timeout:
→ Increase timeout in apps/api/vercel.json (max 30s)

Build Error:
→ Check Vercel build logs
→ Run npm run build locally first
