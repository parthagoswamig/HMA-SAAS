2. DATABASE (PRISMA + SUPABASE) - OPTIMIZATION
   ===========================================

   CONFIGURATION CHANGES:
   ----------------------
   • DATABASE_URL: Uses pgBouncer pooler (port 6543)
     Format: postgresql://...@pooler.supabase.com:6543/postgres?pgbouncer=true&connection_limit=1
   
   • DIRECT_DATABASE_URL: Direct connection (port 5432)
     Format: postgresql://...@pooler.supabase.com:5432/postgres
     Used for: Migrations only
   
   • Connection Parameters:
     - connection_limit=1 (optimal for serverless)
     - pool_timeout=10 (fast timeout)
     - connect_timeout=10 (fast connection)
   
   • Lazy Connection: Connects on first query, not on init
   • Auto-disconnect: Handled by Vercel runtime

   MIGRATION STRATEGY:
   -------------------
   • Development: Use DIRECT_DATABASE_URL
   • Production: Run migrations separately before deployment
   • Command: npm run prisma:migrate:deploy
   • Never run migrations from serverless functions

================================================================================
TROUBLESHOOTING - COMMON ISSUES
================================================================================

ISSUE 1: Cold Start Timeouts
-----------------------------
Symptoms: 504 Gateway Timeout on first request
Solution:
• Increase timeout in vercel.json (max 30s for Pro)
• Optimize Prisma client initialization
• Use Vercel's "Keep Warm" feature
• Consider upgrading to Vercel Enterprise

ISSUE 2: Database Connection Errors
------------------------------------
Symptoms: "Can't reach database server"
Solution:
• Verify DATABASE_URL uses pgBouncer (port 6543)
• Check connection_limit=1 in URL
• Verify Supabase pooler is enabled
• Check IP allowlist in Supabase (should be disabled for pooler)

ISSUE 3: CORS Errors
---------------------
Symptoms: "Access-Control-Allow-Origin" error
Solution:
• Add frontend URL to CORS_ORIGINS environment variable
• Verify credentials: true in CORS config
• Clear browser cache
• Check Vercel environment variables are set

ISSUE 4: JWT Token Errors
--------------------------
Symptoms: "Invalid token" or "Token expired"
Solution:
• Verify JWT_SECRET matches between deployments
• Check token expiration times are reasonable
• Verify JWT_ACCESS_SECRET and JWT_REFRESH_SECRET are set
• Clear localStorage and re-login

ISSUE 5: Build Failures
------------------------
Symptoms: Deployment fails during build
Solution:
• Check Vercel build logs for specific error
• Verify all dependencies are in package.json
• Run prisma generate before build
• Check TypeScript errors locally: npm run build
• Verify Node version matches (20+)

ISSUE 6: Prisma Migration Errors
---------------------------------
Symptoms: "Migration failed" or "Schema out of sync"
Solution:
• Use DIRECT_DATABASE_URL (port 5432) for migrations
• Never run migrations from serverless functions
• Run migrations before deployment
• Use: npm run prisma:migrate:deploy
